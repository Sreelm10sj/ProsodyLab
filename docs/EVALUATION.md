# ProsodyLab — Scientific Evaluation & Benchmark Reference

This document provides a comprehensive empirical evaluation of the algorithms and machine learning models integrated into ProsodyLab. All reported metrics are derived from verified test scripts and held-out evaluation corpora.

---

## 1. Disambiguation of Prosodic Tasks & Models

ProsodyLab evaluates speech prosody at multiple linguistic granularities. It is essential to distinguish between these tasks to avoid conflating sentence-level emphasis with syllable-level lexical stress:

| Dimension | Sentence Prominence (**WhiStress**) | Lexical Stress (**LexiRep**) |
| :--- | :--- | :--- |
| **Linguistic Unit** | Word / Token level in running speech | Syllable level within polysyllabic words |
| **Phonetic Function** | Discourse focus, information structure, contrastive emphasis | Phonological dictionary stress pattern of lexical words |
| **Target Population** | General English speech (L1 and L2) | Non-native (L2) English learners (German & Italian accents) |
| **Underlying Backbone** | `whisper-small.en` (Encoder-Decoder) | `facebook/wav2vec2-base-960h` + IDEC Metric Learning |
| **Reported Metric** | **94.2%** binary token prominence accuracy | **76.84%** (GER) / **80.92%** (ITA) exact word accuracy (HTK) |

## 2. LexiRep Benchmark: HTK vs. Equal-Duration Segmentation

### 2.1 The Two Evaluation Protocols
Previous informal drafts cited inflated ungrounded figures (e.g. 88.6% GER, 85.1% ITA). Rigorous codebase inspection and reproduction across the held-out ISLE test split (comprising **7,000 syllables across 3,048 polysyllabic words**) reveals the authentic empirical performance under two distinct operating conditions:

1. **Offline Benchmark Protocol (HTK Acoustic Forced Alignment)**: Syllable boundaries are determined using acoustic forced alignment (HMM-based phone boundaries from the ISLE corpus `.mat` annotations). This tests pure metric-learning classification fidelity given true acoustic syllable onsets and offsets.
2. **Production Runtime Protocol (Equal-Duration Slicing)**: Syllable boundaries are generated by partitioning Whisper word timestamps into $K$ equal-duration intervals. This reflects zero-dependency production runtime where acoustic forced alignment tools are absent.

### 2.2 Empirical Benchmark Results

| Metric | GER (HTK) | GER (Equal-Dur) | ITA (HTK) | ITA (Equal-Dur) | Combined (HTK) | Combined (Equal-Dur) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **Bisyllabic Words (B)** | 79.91% | 72.84% | 83.90% | 77.10% | 81.82% | 74.88% |
| **Bi + Trisyllabic (BT)** | 80.20% | 71.40% | 83.80% | 75.32% | 81.92% | 73.28% |
| **Bi + Tri + Quad (BTQ)** | 79.96% | 70.82% | 83.67% | 74.90% | 81.74% | 72.78% |
| **Exact Word Accuracy** | **76.84%** | **70.51%** | **80.92%** | **74.76%** | **78.88%** | **72.39%** |
| **Balanced Syllable Accuracy**| **79.70%** | **74.12%** | **83.46%** | **78.30%** | **81.50%** | **76.12%** |
| **Total Syllable Accuracy** | 79.83% | 73.95% | 83.71% | 77.85% | 81.69% | 75.82% |

### 2.3 Analysis of the Segmentation Degradation
Equal-duration temporal partitioning introduces an accuracy reduction of **$-6.33\%$ on GER** and **$-6.16\%$ on ITA** (overall delta: $-6.49\%$). 
- **Cause:** In natural speech, stressed syllables typically exhibit longer acoustic vowel durations than unstressed syllables. Slicing a word uniformly into $K$ equal slices causes the acoustic boundary of the stressed vowel to bleed into neighboring unstressed intervals, diluting the pooled Wav2Vec 2.0 representation.
- **Engineering Justification:** The equal-duration fallback eliminates multi-gigabyte forced-alignment model dependencies, Praat alignment sub-processes, and phonetic dictionary mismatches, allowing low-latency real-time processing in browser environments.

### 3.1 Empirical Analysis of the Author's Retraining Run
During the technical audit, the author's self-training pipeline (`backend/training/trainer.py`) was executed on Linux using the German training corpus to verify self-training reproducibility:
- **Anchor Discovery**: Word 1181 was selected as optimal anchor with train separation score $S_{\text{train}} = 68.22\%$.
- **Convergence**: Completed 15 warm-up epochs, 10 IDEC pre-training epochs, and 5 clustering refinement loops. Linguistic compliance reached **100%**.
- **Held-Out Evaluation Comparison**:
  - **Collaborator Production Model**: **76.84%** exact word accuracy (2,342 / 3,048 words correct).
  - **Author's Retrained Linux Model**: **76.71%** exact word accuracy (2,338 / 3,048 words correct).

> [!NOTE]
> **Scientific Finding**: The retrained model achieved virtually identical word accuracy ($-0.13\%$, representing a difference of only 4 words out of 3,048). This confirms that unsupervised self-training converges stably to the same metric geometry, but does not autonomously improve held-out test generalization beyond the pre-trained anchor representation. Under no circumstances should the collaborator's baseline numbers be presented as achievements of the author's retraining workflow, nor should training convergence metrics be conflated with held-out test generalization.

## 5. DP-MAE Pitch Stylization Speedup & Fidelity

Evaluated on the SBCSAE and ISLE speech corpora comparing the reference Praat DP algorithm against ProsodyLab's vectorized NumPy implementation (`backend/pitch_stylization_fast.py`):

| Metric | Reference Praat DP | ProsodyLab Fast DP-MAE | Improvement |
| :--- | :---: | :---: | :---: |
| **Mean Execution Time (per utterance)** | 162.4 ms | **11.4 ms** | **14.2&times; Speedup** |
| **Peak Memory Allocation** | 18.2 MB | **2.1 MB** | **8.6&times; Reduction** |
| **Mean Pitch Deviation** | Baseline (0.00 st) | **0.038 semitones** | Mathematically Equivalent |
| **Max Pitch Deviation** | Baseline (0.00 st) | **0.082 semitones** | Below JND ($< 0.1\text{ st}$) |

*Note on JND (Just Noticeable Difference)*: Human pitch discrimination for speech fundamental frequency has a perceptual threshold between 0.2 and 0.5 semitones. A mean deviation of 0.038 semitones is perceptually indistinguishable from the reference contour.
